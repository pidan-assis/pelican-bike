# 鹈鹕骑单车 🦤🚲

一只鹈鹕的骑行人生：先是纯动画，后来长成了可玩的游戏。

## 两个版本

- `index.html` — 纯动画版：鹈鹕踩着单车一路向前（2026-10-10）
- `game.html` — 游戏版：三车道躲避障碍（2026-10-11）

## 玩法（game.html）

- ⬆⬇ / W S：换车道（手机上滑 / 下滑也行）
- L：车灯 —— 黑夜里不开灯基本是瞎骑
- B：车铃 —— 按铃能把前面的小动物吓跑
- 空格：暂停
- R / 回车：游戏结束后快速重新开始
- 路锥、石头、水坑随机刷；撞了掉一条命（共 3 条），撞后 1.5 秒无敌闪
- 得分规则：分数 = 躲避障碍数 × 10 + 路程（米）下取整，实时显示在右上角
- 每骑满 500 米会弹出里程碑提示（"500 米！"）并播放提示音，骑得越远难度越高
- 最佳分数与最佳里程会保存在 localStorage（键 `pelicanBest`），刷新页面也不丢

## 两个版本 / 互相跳转

- `index.html` — 纯动画版：鹈鹕踩着单车一路向前。页面底部有 "▶ 玩游戏版" 按钮跳转到游戏版。
- `game.html` — 游戏版：三车道躲避障碍。右下角 "看动画版" 链接返回动画版。

## 技术

纯手写单文件 HTML：SVG 鹈鹕骑手 + Canvas 路面，Web Audio 合成铃声，零依赖，手机 / 桌面都能玩。竖屏下完整显示不裁切，撞击判定按鹈鹕实时位置算。
